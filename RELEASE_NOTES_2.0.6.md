# MediaVault 2.0.6 — Windows Release

## Highlights

MediaVault 2.0.6 is the first release prepared for public Windows distribution.

### Included
- Local-first media library
- Folder and subfolder organization
- Tags and collections
- Saved Searches
- Inbox workflow
- Batch Rename
- Duplicate Manager
- Grid / Compact / Masonry views
- Media Viewer and Inspector
- Notes and Source URL metadata
- Clipboard import
- Backup & Restore
- `Ctrl+Z` delete undo
- Windows installer and portable build

## Download

### Installer
`MediaVault-2.0.6-Setup.exe`

Recommended for most users.

### Portable
`MediaVault-2.0.6-Portable.exe`

Runs without installation.

## Important note about signing

The release binaries are currently unsigned unless a Windows code-signing certificate is configured for the build environment. Windows may therefore show a SmartScreen warning on first launch.

## Storage
